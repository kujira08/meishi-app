# 名刺管理アプリ

大川原染色本舗の社内用。展示会・商談で受け取った名刺を携帯で撮影し、
OCRでテキスト化 → 編集 → 保存する単一HTMLのアプリ。

- 公開URL: https://kujira08.github.io/meishi-app/
- OCR: Tesseract.js (jpn)
- 保存先: 各端末のブラウザの localStorage（サーバーには何も送らない）
- バックアップ: ヘッダー右上の「⋯」からJSONで書き出し／読み込み

## 注意

名刺データは端末内にしかありません。履歴の削除や機種変更で消えるので、
ときどきバックアップを書き出してください。

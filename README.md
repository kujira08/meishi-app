# 名刺管理

社内用。展示会・商談で受け取った名刺を携帯で撮影し、
項目を自動で抽出 → 確認 → 保存する単一HTMLのアプリ。ホーム画面での表示名は「名刺管理」。

- 公開URL: https://kujira08.github.io/meishi-app/
- 抽出: 写真をGAS（名刺OCR中継）経由で Claude API に渡し、項目をJSONで受け取る
- QR: 名刺のQRコードは端末内で解読（jsQR）。vCard / MECARD / URL に対応し、OCR結果より優先
- 両面: 「裏面も撮る」で表裏をまとめて1回のリクエストで読む
- 保存先: 各端末のブラウザの localStorage（サーバーにも中継にも名刺データは残らない）
- バックアップ: ヘッダー右上の「⋯」からJSONで書き出し／読み込み

## 注意

名刺データは端末内にしかありません。履歴の削除や機種変更で消えるので、
ときどきバックアップを書き出してください。

iPhoneは Safari で開いて「共有 → ホーム画面に追加」。
最初からホーム画面版で使い始めてください（Safariと保存領域が分かれることがあります）。
